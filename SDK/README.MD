# PsyQ SDK
This folder contains a highly stripped down version of the PsyQ SDK.  
It contains a setup which can build Frogger 2, but not a whole lot else.  
Frogger 2 uses runtime libraries v4.3.  

I put it together by combining various different things:  
 - PsyQ includes/libraries from 4.3.  
 - Executables / compilers from Blitz Games backups.  
 - A few proprietary Blitz Games tools.  
 - CPE2EXE (Orion's Version, Modified by Kneesnap to work with CPE files that have many sections. Modified code is at cpe2exe.c)  
 - Libcrypt
